## Project Overview

**Genetics Toolkit** is a Python-based educational project that aims to simplify classical genetics calculations. The toolkit is designed to help students visualize genetic inheritance patterns and automate calculations that are traditionally performed manually.

The project is being developed module by module and will continue to expand throughout my undergraduate studies.

---

## Current Features

- ✅ Punnett Square Generator
- ✅ Genotype Ratio Calculator
- ✅ Standardized genotype notation (e.g., tT → Tt)
